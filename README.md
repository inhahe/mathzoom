# mathzoom

An endless, accelerating zoom-out through a self-similar formula for an
unimaginably large number — power towers of 2s, stacked under underbraces, chained
with right braces, and nested for ever. Every glyph is TeX's own typesetting,
drawn as vectors.

**Open `index.html` in a browser** (double-click works; no server needed).

- Click to pause / resume, `R` to restart.
- URL parameters tune it, e.g. `index.html?vmax=3` (faster top speed) or
  `index.html?v0=0.3` (faster start). See `design.md` for all of them.

How it works — the notation, why the zoom is exactly self-similar, the TeX
pipeline, and the renderer — is in [`design.md`](design.md).
